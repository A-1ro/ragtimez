## What's Changed
Anthropic has implemented shared memory between Claude's chat and Cowork features, eliminating the need for users to repeatedly explain project or setting contexts. This change makes interactions with AI more efficient and natural.
(Source: [techcrunch.com](https://techcrunch.com/2026/08/25/claude-cowork-finally-remembers-what-you-told-the-app-in-chat/))

## How It Works
The shared memory feature in Claude Cowork persists user input between chat sessions and the Cowork application, allowing it to be automatically referenced in subsequent conversations. This saves users the trouble of re-entering past instructions or settings. The specific technical implementation is not detailed in the official documentation.
