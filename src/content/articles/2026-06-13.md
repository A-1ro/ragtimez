## Rocket Close の Supercharger: エージェント AI による不動産権利調査の自動化

Rocket Close が AWS と共同開発した Supercharger は、不動産権利調査業務をエージェント AI で効率化する実用的なソリューションです。従来の権利調査では、複数のシステム、州ガイド、郡要件を横断して手動で情報を検索する必要があり、1件の調査に数時間を要していました。

Supercharger は Strands Agents SDK、Amazon Bedrock、Amazon Bedrock Knowledge Bases、Model Context Protocol (MCP) ツールを組み合わせて構築されています。Anthropic Claude Large Language Model を Amazon Bedrock 経由で利用し、将来的に異なる LLM への切り替えも可能な柔軟性を持っています。

（出典: [Building Supercharger: How Rocket Close optimized title operations with agentic AI](https://aws.amazon.com/blogs/machine-learning/building-supercharger-how-rocket-close-optimized-title-operations-with-agentic-ai/)）

## システムアーキテクチャと 6 つの中核機能

Supercharger は 6 つの相互接続された機能で構成されています。会話型分析、州レベルの権利調査支援、API ベース統合、ガードレールと回答精度、ログ記録・監視、統合データアクセスです。

セキュリティ面では Amazon Bedrock Guardrails と行レベルデータ権限を組み合わせ、顧客機密データへの偶発的アクセスを防止します。すべての会話は完全な監査証跡とともにログ記録され、コンプライアンス要件を満たします。Rocket Close の運用データベースと統合し、注文情報、標準手順、州レベル権利調査のポリシーにアクセスできます。

（出典: [Building Supercharger: How Rocket Close optimized title operations with agentic AI](https://aws.amazon.com/blogs/machine-learning/building-supercharger-how-rocket-close-optimized-title-operations-with-agentic-ai/)）

## Amazon API Gateway の新機能: AgentCore Gateway 統合

Amazon API Gateway が Amazon Bedrock AgentCore Gateway のターゲットとして REST API をサポートするようになりました。この機能は 2025年12月2日に追加され、エージェント AI システムと既存の REST API を直接統合できます。

API Gateway では Application Load Balancer との プライベート統合、REST API でのレスポンスストリーミング、開発者ポータル機能も新たにサポートされています。開発者ポータルは顧客が API を発見・テストするための一元化された場所を提供し、ポータル製品として共有したいサービスや機能を表現できます。

今すぐ試すには、AWS コンソールの API Gateway セクションで「Add an API Gateway REST API as a target for Amazon Bedrock AgentCore Gateway」のドキュメントを参照してください。

（出典: [Document history - Amazon API Gateway](https://docs.aws.amazon.com/apigateway/latest/developerguide/history.html)）

## API ドキュメント作成の実装パターン

API Gateway では REST API の包括的なドキュメント作成機能を提供しています。API エンティティ、リソース、メソッド、パラメータ、レスポンスなど、個別の API 要素に対してドキュメントパーツを作成できます。

ドキュメント作成は API Gateway コンソール、REST API、AWS SDK、AWS CLI を通じて実行可能です。外部の OpenAPI ファイルからドキュメントパーツをインポート・エクスポートすることもできます。作成したドキュメントは API ステージと関連付け、ステージ固有のドキュメントスナップショットを外部 OpenAPI ファイルにエクスポートして配布できます。

API ドキュメントを開発者と共有するには、ReadMe や SmartBear の SwaggerHub などの開発者ポータルと統合する方法があります。

（出典: [Documentation for REST APIs in API Gateway - Amazon API Gateway](https://docs.aws.amazon.com/apigateway/latest/developerguide/api-gateway-documenting-api.html)）

## まとめ

- Strands Agents SDK と Amazon Bedrock を組み合わせることで、不動産権利調査のような複雑な業務プロセスを自然言語インターフェースで自動化できるようになる
- Amazon API Gateway の AgentCore Gateway 統合により、既存の REST API をエージェント AI システムのターゲットとして直接接続し、レガシーシステムとの橋渡しが可能になる
- API Gateway の新しい開発者ポータル機能と包括的なドキュメント作成機能を活用すれば、エージェント AI システムの API を外部開発者向けに体系的に公開・管理できる
- Rocket Close の事例から、行レベルデータ権限と監査証跡を組み合わせたセキュリティ設計により、機密性の高い業務データを扱うエージェント AI システムでもコンプライアンス要件を満たした運用が実現できる
