## AWS and Superblocks Integration Announcement

According to a report by TechCrunch, AWS is working on an effort to embed Superblocks, a vibe coding tool, into the private cloud environments of AWS customers. This integration will enable Superblocks to run within the closed domains of AWS customers, which is the core fact reported in this announcement. TechCrunch describes this move as having "big implications," positioning it as a significant development that affects the industry structure, rather than just a simple feature addition.

(Source: [TechCrunch](https://techcrunch.com/2026/08/03/aws-is-helping-vibe-coding-startup-superblocks-and-the-implications-are-big/))

## The Point of "App and Model Separation"

The TechCrunch article describes this integration as "another step towards decoupling apps from models." This means that the structure of vibe coding, where generated applications were strongly tied to specific AI models or vendors' execution environments, is moving towards a direction where the application execution platform (in this case, AWS customers' private clouds) and model selection/providers can be separated. However, the article does not specify which API or architecture layer will achieve this separation.

(Source: Ibid. [TechCrunch])
