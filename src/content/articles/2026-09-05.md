## 何が新しくなったか  
Amazon Bedrock AgentCore は、マルチモーダルな WhatsApp 注文アシスタントの構築を可能にし、複数のチャネル（テキスト、音声ノート、通話）を統合したバックエンドを提供します。このソリューションでは、Meta WhatsApp Business Platform がカスタマーフロントとして機能し、Amazon Nova 2 と Amazon Nova 2 Sonic がテキストおよび音声処理を担当します。また、Model Context Protocol (MCP) を通じてレストランのバックエンドに接続されます。（出典: [aws.amazon.com](https://aws.amazon.com/blogs/machine-learning/deploy-a-multimodal-whatsapp-ordering-assistant-with-amazon-bedrock-agentcore/)）

## 仕組みの詳細  
AgentCore は、チャネルと注文ロジックを分離することで、チャネルの追加や削除時にバックエンドを変更することなく運用できます。具体的には、AWS Cloud Development Kit (AWS CDK) を使用して全システムをデプロイし、Amazon Bedrock Converse API を介してテキスト処理を行います。また、Amazon Nova 2 Lite がテキスト処理を担当し、Amazon Nova 2 Sonic がリアルタイムの音声処理を実行します。（出典: [aws.amazon.com](https://aws.amazon.com/blogs/machine-learning/deploy-a-multimodal-whatsapp-ordering-assistant-with-amazon-bedrock-agentcore/)）

## メモリライフサイクル管理  
AgentCore のメモリライフサイクルポリシーは、長期間運用されるエージェントが古いコンテキストを保持しないようにする仕組みです。このソリューションでは、AWS Step Functions と Amazon Bedrock を使用して、毎晩のライフサイクルワークフローを実行します。これにより、エージェントのメモリをスコアリング、統合、削除して、応答品質とコンプライアンスを維持します。（出典: [aws.amazon.com](https://aws.amazon.com/blogs/machine-learning/designing-lifecycle-policies-for-agentcore-memory/)）

## エンジニアが今日使えるポイント  
- AWS CDK を使用して、マルチモーダルな WhatsApp 注文アシスタントを構築できます。  
- Model Context Protocol (MCP) を活用し、エージェントのメモリライフサイクルを管理できます。  
- Amazon Bedrock Converse API を介して、テキスト処理をカスタマイズできます。  

## まとめ  
- AWS CDK を使ってマルチモーダルな WhatsApp 注文アシスタントを構築できる  
- MCP を活用してエージェントのメモリライフサイクルを管理できる  
- Amazon Bedrock Converse API を使用してテキスト処理をカスタマイズできる
