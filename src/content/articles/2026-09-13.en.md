## What Has Changed
Perplexity has integrated GPT-6 Astra into an end-to-end system, performing creation of communications, modification of software, and monitoring of production systems. Compared to traditional models, the frequency of checks has decreased significantly.
(Reference: [Perplexity trusts GPT‑6 Astra with end-to-end systems](https://openai.com/index/perplexity-improving-accuracy-with-astra))

## How It Works
GPT-6 Astra generates small test programs to test application workflows. This model simulates the responses of other services (e.g., language model APIs or connectors) and verifies the application's reactions, allowing for testing of the entire workflow from start to finish.
(Reference: aforementioned [Perplexity trusts GPT‑6 Astra with end-to-end systems])

## Migration Procedure
When integrating GPT-6 Astra into production systems, Perplexity made changes to existing workflows, including the introduction of automated code testing and real-time monitoring.
(Reference: aforementioned [Perplexity trusts GPT‑6 Astra with end-to-end systems])

## Performance Characteristics
GPT-6 Astra demonstrates top-tier performance in FrontierMath Tier 4, ARC-AGI 3, and TerminalBench-4.0, enabling fast and accurate processing of complex tasks such as scientific work and software engineering.
(Reference: [Introducing GPT-6-Astra: The most intelligent and aligned model in the world](https://community.openai.com/t/introducing-gpt-6-astra-the-most-intelligent-and-aligned-model-in-the-world/1394703))

## Known Limitations
GPT-6 Astra's zero data retention is limited to qualified API customers and is only available on corresponding endpoints.
(Reference: [GPT-6 Astra: The next generation in intelligence for work - OpenAI](https://openai.com/index/gpt-6-astra-next-generation-work))

## Summary
- By using GPT-6 Astra, automatic testing can be introduced into Perplexity's workflows, reducing the frequency of manual checks
- Integrating GPT-6 Astra into end-to-end system monitoring enables real-time monitoring of production environments
- Production system changes can be automated using GPT-6 Astra, improving development cycle efficiency
- With optimal performance in FrontierMath Tier 4 and TerminalBench-4.0, it is suitable for complex business processing
- The zero data retention feature can be utilized to achieve customized privacy protection for enterprises
