## Claude Platform on AWSが一般提供開始 — Anthropicのネイティブ体験をAWSアカウント経由で利用可能に

AWS上でClaude Platform on AWSが一般提供を開始した。これは、開発者がAWSアカウントを通じてAnthropicのネイティブClaude Platform体験に直接アクセスできる新サービスである。

従来、Claude APIを利用するには別途Anthropicとの契約や認証情報が必要だった。Claude Platform on AWSでは、既存のAWSアカウント、請求、IAMポリシーをそのまま活用できる。AWSは、ネイティブClaude Platform体験を提供する最初のクラウドプロバイダーとなった。

（出典: [AWS Machine Learning Blog](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/)）

## 利用可能な機能とAPI

Claude Platform on AWSでは、Anthropicが直接提供するものと同じAPI、機能、コンソール体験が利用できる。具体的には以下の機能が含まれる：

- Messages API
- Claude Managed Agents（ベータ）
- advisor tool（ベータ）
- web searchとweb fetch
- MCP connector（ベータ）
- Agent Skills（ベータ）
- code execution
- files API（ベータ）

これらの機能により、開発者は従来のテキスト生成に加えて、エージェント機能やツール連携を活用したより高度なアプリケーションを構築できる。

（出典: [AWS Machine Learning Blog](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/)）

## セットアップと認証方法

Claude Platform on AWSの利用開始は3つのステップで完了する。まず、AWS Marketplaceでアカウントを有効化する。次に、ワークスペースを作成してプロジェクトや環境を分離し、IAMポリシーでアクセス制御を設定する。

認証方法は2つ提供される。AWS Signature Version 4を使用したIAM認証と、従来のAPIキー認証である。IAM認証を使用する場合、ワークスペースARNを使ってIAMポリシーで細かいアクセス制御が可能になる。

Claude Platform on AWSはAnthropicが運営し、リクエストとデータはAWSセキュリティ境界の外で処理される。これは、特定の地域データ常駐要件がないチームに適している。

（出典: [AWS Machine Learning Blog](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/)）

## Amazon Bedrock上のClaudeモデルとの使い分け

Claude Platform on AWSは、Amazon Bedrock上のClaudeモデルを補完する位置づけである。Amazon Bedrockは地域データ常駐やより厳格なセキュリティ要件がある企業向けに設計されている。

一方、Claude Platform on AWSは、Anthropicのフル機能セット（エージェント機能、ツール連携、MCP connector等）を活用したい開発者に適している。データ処理がAWSセキュリティ境界外で行われることを許容できる場合、より豊富な機能を利用できる。

開発者は、プロジェクトの要件に応じてどちらのアプローチを選択するかを決定できる。

（出典: [AWS Machine Learning Blog](https://aws.amazon.com/blogs/machine-learning/introducing-claude-platform-on-aws-anthropics-native-platform-through-your-aws-account/)）

## まとめ

- Claude Platform on AWSを通じて、既存のAWSアカウントでAnthropicの全機能セットにアクセスし、別途契約や認証情報なしでClaude Managed AgentsやMCP connectorを活用したアプリケーションを構築できる
- IAM認証とワークスペースARNを組み合わせることで、企業内の複数チームや環境に対して細かいアクセス制御を実装し、セキュアなAI開発環境を構築できる
- Amazon Bedrock（地域データ常駐重視）とClaude Platform on AWS（機能豊富性重視）の特性を理解して使い分けることで、プロジェクト要件に最適なClaude活用戦略を選択できる
