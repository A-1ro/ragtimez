## Microsoft Foundryの最新技術革新  
（出典: [Microsoft Foundry](https://azure.microsoft.com/en-us/blog/frontier-models-and-production-agents-advancing-microsoft-foundry-for-the-agentic-era/)）  

Microsoft Foundryは、AIエージェントの本格的な運用を可能にするプラットフォームとして進化を遂げています。2026年7月のアップデートでは、GPT-5.6の一般提供と、エージェントサービスの強化が注目されます。  

### GPT-5.6の一般提供とエージェントサービスの拡張  
（出典: [Microsoft Foundry](https://azure.microsoft.com/en-us/blog/frontier-models-and-production-agents-advancing-microsoft-foundry-for-the-agentic-era/)）  
- **GPT-5.6の一般提供**: OpenAIの最新モデルがMicrosoft Foundryで利用可能に。28のグローバルリージョンとAsia-Pacific Data Zoneで動作し、企業向けに柔軟なモデル選択を提供。  
- **ホストエージェントの導入**: Foundry Agent Serviceでホストエージェントを運用可能に。開発者はMicrosoft 365内でのエージェント配置が可能で、セキュリティとコンプライアンスを確保。  
- **10万を超える企業の利用**: 10万以上の組織がFoundry上でエージェント開発を実施し、AdobeやTata Consultancy Servicesなどが本番環境で運用。  

### エンタープライズ向けの強化機能  
（出典: [Microsoft Foundry](https://azure.microsoft.com/en-us/blog/frontier-models-and-production-agents-advancing-microsoft-foundry-for-the-agentic-era/)）  
- **3つの柱**:  
  1. **開発**: GitHub CopilotとVisual Studio Codeでのエージェント構築をサポート。  
  2. **運用**: 企業向けのアイデンティティ、セキュリティ、コンプライアンス制御を統合。  
  3. **配布**: Microsoft 365を通じたエージェントの拡散を可能に。  
- **モデル選択の柔軟性**: オープンソースモデルやタスク固有モデルとの連携で、ワークロードに最適なモデルを選び放題。  

### エンジニアが今日できるアクション  
（出典: [Microsoft Foundry](https://azure.microsoft.com/en-us/blog/frontier-models-and-production-agents-advancing-microsoft-foundry-for-the-agentic-era/)）  
- **エージェントのデプロイ**: Microsoft FoundryのGetting Startedページで、GPT-5.6を活用したエージェント構築を開始。  
- **セキュリティ設定の最適化**: 企業のアイデンティティ管理とコンプライアンスポリシーをFoundryに統合。  
- **エコシステムの拡張**: GitHub Copilot SDKやClaude Agent SDKとの連携で、既存の開発ワークフローにエージェントを埋め込み。  

## まとめ  
- **GPT-5.6を活用したエージェント開発**: Foundryのエージェントサービスで、企業向けにカスタムエージェントを構築可能。  
- **セキュリティとコンプライアンスの強化**: 企業のアイデンティティ管理とFoundryの制御機能を連携させ、本番環境での運用を安全に。  
- **エコシステムの拡張**: 既存の開発ツール（GitHub Copilot、Claude Agent）とFoundryを統合し、開発効率を向上。
