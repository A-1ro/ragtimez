## Azure Kubernetes Fleet Manager のクロスクラスターネットワーキング機能がパブリックプレビューで公開

Microsoft Azure は、複数の Kubernetes クラスター間でのシームレスなネットワーキング機能を提供する **Azure Kubernetes Fleet Manager のクロスクラスターネットワーキング機能** をパブリックプレビューとして発表した。この機能は **Advanced Container Networking Services** を基盤とし、Cilium ベースの透明な East-West マルチクラスターネットワーキングを実現する。

従来のマルチクラスター環境では、複数の Azure Kubernetes Service (AKS) クラスター間の通信に複雑な VPN やゲートウェイが必要だった。新機能により、プラットフォームチームはインフラストラクチャの詳細を開発者から抽象化し、アプリケーションを中断することなくクラスターレベルの変更を可能にする。

（出典: [Azure Blog](https://azure.microsoft.com/en-us/blog/powering-multi-cluster-workloads-with-seamless-cross-cluster-networking-for-azure-kubernetes-fleet-manager/)）

## マルチクラスターネットワーキングの課題解決

規制要件、地域的な災害復旧、または障害ドメインの分離により、あらゆる規模の組織が複数の AKS クラスターを運用している。しかし、これらのクラスターの管理には従来「**ネットワーキング税**」が課せられていた。

従来のアプローチでは複雑な VPN、ゲートウェイ、手動サービスディスカバリーに依存し、レイテンシと運用の複雑さが増大していた。特に大規模なクラスターフリートを運用する場合、チームはフェイルオーバー、共有サービスアーキテクチャ、容量やレイテンシのためのリージョン間でのワークロードの seamless な移行をサポートするための一貫性のある信頼性の高いクロスクラスター接続を必要としている。

（出典: [Azure Blog](https://azure.microsoft.com/en-us/blog/powering-multi-cluster-workloads-with-seamless-cross-cluster-networking-for-azure-kubernetes-fleet-manager/)）

## Cilium ベースの高性能ネットワーク実装

Azure Kubernetes Fleet Manager は、マルチクラスター管理への対応として設計されている。新しいクロスクラスターネットワーキング機能は、Cilium ベースの管理された高性能ネットワークを提供し、フリート全体にわたってスパンできる。

この実装により、数個のクラスターから大規模なクラスターフリートまで、一貫した信頼性の高いクロスクラスター接続が実現される。プラットフォームチームは、開発者がアプリケーションを中断することなく、インフラストラクチャの詳細を抽象化し、クラスターレベルの変更を seamless に実行できるようになる。

（出典: [Azure Blog](https://azure.microsoft.com/en-us/blog/powering-multi-cluster-workloads-with-seamless-cross-cluster-networking-for-azure-kubernetes-fleet-manager/)）

## 実装の開始方法

Azure Kubernetes Fleet Manager のクロスクラスターネットワーキング機能を試すには、Microsoft Learn の公式ドキュメントから開始できる。パブリックプレビュー段階のため、本番環境での使用前に十分な検証が推奨される。

Advanced Container Networking Services の概要についても、Azure の公式ドキュメントで詳細を確認できる。これらのリソースには、設定手順、制限事項、ベストプラクティスが含まれている。

（出典: [Azure Blog](https://azure.microsoft.com/en-us/blog/powering-multi-cluster-workloads-with-seamless-cross-cluster-networking-for-azure-kubernetes-fleet-manager/)）

## まとめ

- Azure Kubernetes Fleet Manager のクロスクラスターネットワーキング機能により、複数の AKS クラスター間で VPN や複雑なゲートウェイ設定なしに直接通信を実現できる
- Cilium ベースの実装で、従来の「ネットワーキング税」を排除し、レイテンシと運用複雑さを削減した環境を構築できる
- Advanced Container Networking Services を活用することで、大規模なクラスターフリートでも一貫した高性能ネットワーキングを実現できる
- Microsoft Learn の公式ドキュメントから設定を開始し、パブリックプレビュー環境でマルチクラスター管理の新しいアプローチを検証できる
